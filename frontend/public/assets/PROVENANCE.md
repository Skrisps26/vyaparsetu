# Bundled demonstration assets

- demo-input.wav and demo-reply.wav: synthesized locally with eSpeak NG Malayalam voice (`ml`), synthetic scenario only. Not Gnani/Timbre audio.
- ../fonts/NotoSansMalayalam-Regular.ttf: unmodified static Noto Project font from https://raw.githubusercontent.com/notofonts/notofonts.github.io/main/fonts/NotoSansMalayalam/full/ttf/NotoSansMalayalam-Regular.ttf ; SIL OFL1.1 in ../fonts/OFL.txt.
- Browser UI webfonts: @fontsource/noto-sans-malayalam, same Noto OFL license.
