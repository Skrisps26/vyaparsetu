# VyaparSetu

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Approved: React/Vite/TypeScript, Tailwind, shadcn/ui, Motion, wavesurfer; Python/FastAPI/Pydantic, SQLite, official Gnani SDK and OpenAI-compatible self-hosted Evon.

## Users
Kerala kirana shopkeepers, hands busy in noisy shops, speaking Malayalam mixed with English and Manglish.

## Product Purpose
Turn messy spoken bills and mid-sentence corrections into a reviewed invoice, synthetic credit entry and spoken Malayalam confirmation. Search arbitrary real products and show price and tax evidence without inventing missing facts.

## Operating Context
Local hackathon build for a public sixty-second video; responsive laptop and phone-sized view. REST push-to-talk first, persistent local ledger.

## Capabilities and Constraints
One USE_MOCKS switch, cached demo isolated from live ledger, real product lookup with source/pack/date evidence, inclusive/exclusive tax math, PDF export, bilingual UI and theme. No real customer identities/financial identifiers. No GPU funds now; do not provision. Public GitHub Skrisps26/vyaparsetu, verified-module pushes. Missing credentials never disable manual billing/search.

## Brand Commitments
VyaparSetu; Malayalam-first, clear, trustworthy, high contrast, large touch controls. Approved operate layout and slate/indigo visual direction remain pinned.

## Evidence on Hand
Synthetic Demo Kili fixture: rice correction two to three kilos plus soap, bill149.60 and balance249.60. Official model API documentation researched. No actual model inference or authoritative tax dataset imported at project start. Never substitute synthetic results for live proof.

## Product Principles
- Financial arithmetic belongs in deterministic Decimal code.
- Price, identity and GST classification are separate evidence.
- Review ambiguity before posting; replay never posts twice.
- Show mock/cached/manual/live provenance honestly.

## Accessibility & Inclusion
Malayalam/English labels, keyboard operation, reduced motion, 48px touch controls and phone-sized layout.
